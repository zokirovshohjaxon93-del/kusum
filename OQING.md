# Kusum — Telegram Mini App va telefon ilovasi

## A. Saytni joylash (GitHub Pages, bepul)
1. github.com → **Sign up** (ro'yxatdan o'ting).
2. Yuqoridagi **+** → **New repository** → nomi: `kusum` → **Public** → **Create repository**.
3. Ochilgan sahifada **"uploading an existing file"** ni bosing → shu papkadagi BARCHA fayl va papkalarni sudrab tashlang → pastda **Commit changes**.
   (Bir martada 100 tagacha fayl. Ko'p bo'lsa: avval `yoriqnoma` papkasidan tashqari hammasi, keyin `yoriqnoma` papkasi.)
4. **Settings → Pages** → Source: *Deploy from a branch* → Branch: `main`, `/ (root)` → **Save**.
5. 1–2 daqiqadan keyin manzil chiqadi: `https://FOYDALANUVCHI-NOMI.github.io/kusum/`

## B. Telegram bot va Mini App
1. Telegramda **@BotFather** → `/newbot` → nom: `Kusum yordamchi` → username: masalan `kusum_yordamchi_bot`.
2. `/mybots` → botingiz → **Bot Settings → Menu Button → Configure menu button** → A5-dagi manzilni yuboring → tugma nomi: `📚 Kusum`.
3. (Ixtiyoriy, chiroyli havola uchun) `/newapp` → botni tanlang → nom va tavsif → rasm sifatida `miniapp_rasm_640x360.png` → manzil → qisqa nom `kusum`.
   Natija: `t.me/kusum_yordamchi_bot/kusum` — bosilganda ilova to'g'ridan-to'g'ri ochiladi.

## C. Telefon ekraniga ilova qilib qo'yish
- **Android (Chrome):** manzilni oching → ⋮ → **Bosh ekranga qo'shish / Ilovani o'rnatish**.
- **iPhone (Safari):** manzilni oching → **Ulashish** → **Bosh ekranga qo'shish**.
Ilova ikonkasi Kusum belgisi bo'ladi, to'liq ekranda ochiladi. Bir marta ochilgan kartochka va PDF'lar internet yo'q paytda ham ochiladi.
